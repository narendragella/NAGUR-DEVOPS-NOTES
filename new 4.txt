1️⃣ Developer pushes code to Git

“In our project, developers push code to GitHub. We have webhooks configured, so any code commit automatically triggers Jenkins.
Jenkins pulls the code and uses Maven to build the application and generate an artifact. That artifact is stored in Nexus with proper versioning
After the artifact is ready, we update the version in Git and trigger deployment using AWX.
In AWX, we sync inventory, select the deployment template, choose the environment and target servers, and provide credentials.
Before deployment, we stop the Tomcat service, deploy the new artifact, and restart the service.
After deployment, we validate using PDT and basic functional testing.
Once it is verified in non-production, the same version is promoted to production after CR approval during the maintenance window.”
