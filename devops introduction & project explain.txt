✅ 1. “Explain Your Current Project in Detail”
Sample Answer (2–3 Minutes)

“In my current role, I am working on an on-premise CI/CD automation and deployment platform that supports multiple applications used by internal and external users.

The main objective of this project is to automate the build, test, and deployment process and ensure reliable application delivery across development, testing, and production environments.

We use Git for source code management and Jenkins for building CI/CD pipelines. Whenever developers push code to Git, the pipeline is triggered using webhooks. The pipeline performs code checkout, build, testing, Docker image creation, and deployment.

We containerize applications using Docker and deploy them to Kubernetes clusters. We manage rolling updates, scaling, and deployment verification using Kubernetes features.

For infrastructure management, we use Terraform to provision servers and related configurations. We follow Infrastructure as Code practices to maintain consistency across environments.

We use Ansible playbooks for configuration management, such as installing packages, configuring services, and setting up application dependencies.

Monitoring is done using Prometheus, Grafana, and Dynatrace. We create dashboards and alerts to monitor CPU, memory, disk usage, and application health.

My responsibilities include maintaining CI/CD pipelines, supporting deployments, troubleshooting issues, monitoring systems, and automating manual tasks using Bash and Python scripts.

This project has helped improve deployment speed, reduce manual effort, and increase system stability.”
